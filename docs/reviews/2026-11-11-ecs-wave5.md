## Changes

1. The environment lint rejects direct/computed reads, process destructuring,
   named/default/namespace process imports, require and dynamic imports across
   application, package and module runtime source. ESLint fixtures exercise all
   three scopes. Operator audit and rotation share a typed projection. All
   exemptions and their reasons live in
   `tooling/config/environment-policy.mjs`. The single standalone Better Auth
   schema compiler remains exempt; it validates a disposable loopback target.
2. The exhaustive RLS proof starts with `prepareTenantDatabase` and
   `createAppRole`. It applies no schema or grant SQL by hand. It verifies 316
   checks across all 31 tenant tables. The separate tenant-core legacy upgrade
   integration test preserves the old tenant row and timestamp while removing
   the provider-specific organization column. No migration SQL changed.
3. Turbo caches generated `sql/**` as well as dist and Next outputs. Canonical
   migration SQL is a global build input. CI deletes generated package dist and
   module SQL, asserts every selected build task restores from local cache, then
   validates packages again. It never deletes canonical migration SQL.
4. E2E listing bypasses database/server preparation and execution-stat aggregation.
   Its regression test deliberately supplies an invalid database-service port.
5. `pnpm release:local-proof` versions and builds a disposable copy, runs the
   package validator, publishes all 23 public packages only to a random loopback
   Verdaccio 6.10.5 registry, and compares registry tarballs by SHA-512 and exports.
   A clean Node 22 container installs the CLI from Verdaccio and downloads all
   project packs from it, then scaffolds and starts a synthetic tenant. The
   shared startup check proves typecheck, home 200, anonymous session 401, login
   303 and authenticated session 200. CI runs the same proof. Verdaccio is MIT
   licensed. npm provenance needs GitHub OIDC and remains verifiable only in the
   owner-gated npm release workflow. Local proof is not provenance evidence.
6. Both identity DX paths and the local deployment smoke run with actual npm
   downloads. Durations below are measured on the loaded host.

## Failed attempts and reruns

- An initial env-fixture attempt before dependency installation failed because
  ESLint was absent. Frozen installation and subsequent fixtures passed.
- The first legacy test invocation did not enable the ephemeral harness's Unix
  socket transport. It failed before collecting tests, in 19.923 seconds. The
  corrected invocation passed all 12 tests in 26.977 seconds.
- The first quality gate failed the CI package typecheck in 199.677 seconds:
  a literal dynamic import caused NodeNext to follow provisioning source with
  extensionless imports. The script now uses the established dynamic-path
  pattern. The rerun passed all 112 tasks in 436.239 seconds, with 2,050 passed,
  zero failed and 75 skipped tests.
- The first database sequence failed in 66.609 seconds before one suite could
  collect tests because a concurrent forced rebuild removed a package entry.
  The second failed audit CLI integration in 56.905 seconds because the newly
  shared config import lacked the `.ts` extension required by direct Node
  TypeScript stripping. That import and package typecheck configuration were
  corrected before the final sequence. These failures are not passes.
- Local publication development attempts failed in 18.678 seconds for an
  absolute pnpm pack filename, 32.813 seconds for an incomplete concurrent
  build snapshot, and 210.165 seconds for an unavailable image tag. The proof
  now normalizes pack filenames and builds its own temporary source copy.
- The next local proof timed out during registry startup in 288.376 seconds.
  A focused reproduction showed the host umask `0077` made its mounted config
  unreadable to Verdaccio's non-root user. Explicit read permission fixes the
  non-secret config file. The subsequent full proof result is below.
- The first Semgrep scan returned zero findings but timed out on one generated
  validator. It is incomplete evidence. Repeating it once with `--timeout 60`
  completed in 16.346 seconds with two rules over 879 files and zero findings.
- A broad Gitleaks directory scan included ignored dependencies/builds and used
  the tarball-specific policy, reporting 135 findings. The source-only scan
  includes tracked and untracked nonignored repository files and the repository
  policy. It completed with zero findings in 7.099 seconds. Package tarballs
  independently pass their own Gitleaks scan.
- The first Trivy filesystem scan raced a rebuilding dist directory and failed.
  The source-only rerun completed in 7.846 seconds: three medium vulnerabilities,
  no high/critical findings and no misconfigurations. The production pnpm audit
  reports one low and five moderate advisories, with zero high/critical.
