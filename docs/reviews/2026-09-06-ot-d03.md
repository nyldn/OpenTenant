# OT-D03 design evidence

Date: 2026-09-07

Task: specify durable quality-contract binding.

Actual worker model and effort: `gpt-5.6-sol`, `high`. The coordinator verified

Delivered design:

- Immutable contract and evaluation records bind one trusted tenant-private
  module to its exact module version and SHA-256 artifact digest.
- Unchanged logical contracts may bind consecutive artifacts only when their
  normalized body and digest are identical. Conflicting reuse fails.
- Contract/evaluation writes append their exact audit reference in the same
  transaction. Reads recheck tenant ownership and exact permissions, verify
  digests and commit bounded read evidence before returning data.
- Evaluator-defined mismatch, weakening and incoherent-composition rejections
  remain durable evidence. Early rejection uses jointly null effective-contract
  fields; embedded contract references stay distinct from hashes of complete
  run and result bodies.
- The required PostgreSQL matrix covers tenant binding, version/digest mismatch,
  duplicate submission, append-only history and baseline comparison without
  skipped integration tests. `OT-QC01` owns schema/store work; `OT-QC02` owns
  authorized application readback.
