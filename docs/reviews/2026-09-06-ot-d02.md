# OT-D02 design evidence

Date: 2026-09-07

Task: specify persistent, review-only Support AI with inert voice fields.

Actual worker model and effort: `gpt-5.6-sol`, `high`, with a Luna-owned UI
packet defined in the contract. The coordinator verified and corrected the
assembled design. Reviewers: fresh `gpt-6-astra`, `high`, for each revision.

Delivered design:

- One tenant-staff request can produce a suggestion artifact for human review.
  It cannot send a reply, mutate ticket fields, publish knowledge, touch a
  repository, start a sandbox or release code.
- Every request, read and review rechecks the active tenant, module, ticket and
  both required permissions. Request content cannot select tenant, actor,
  provider, model, consent, voice or knowledge scope.
- Request, prepared policy, linked provider attempt, terminal, validated
  suggestion, human review and content-free audit evidence have durable,
  tenant-bound contracts. Preparation and execution references are verified
  across databases, including actual credential origin and the execution
  terminal.
- The applied voice version and digest are immutable. Only `bannedWords` reaches
  behavior, as whole-token refusal after rendering. Preferred words, examples
  and style fields remain inert.
- A closed table maps all current router and stream failures. Interrupted
  requests use a server-owned deadline, stable zero-terminal readback and
  locking that refuses late suggestions.
- `SAI-01` owns the Sol store/API work. `SAI-02` owns the separate Luna review
  panel. Ticket-only Support Agent P0 is a later independent classification
  phase; P1 through P4 remain deferred in order.

Verification: source references, prose checks and `git diff --check` passed. The
first Astra review found missing router-failure mappings, ambiguous preparation
versus execution evidence and no interrupted-request state. The corrected
contract adds each boundary and its negative tests. A fresh reviewer accepted
`c6091a6` with no blocking findings.

Remaining product gates: live provider, region, retention, data boundary and
spend; rejected-output quarantine policy; consent wording that covers retrieved
knowledge; evaluation sourcing; shared knowledge publication/revocation;
managed-support composition; and any broader voice conditioning.

Marketing impact: `truth`. Status: `accepted` as an implementation-ready design,
not as delivery of Support AI or the autonomous Support Agent.
