# Contributing to OpenTenant

OpenTenant’s source is public. External code, documentation, design, and asset
contributions are currently closed while the project finalizes its stewardship
and contribution agreement. Use issues for general project feedback.

This temporary gate protects contributors and the project while the legal
project steward, provenance review, and contributor agreement are completed.
It also preserves the option to offer the AGPL-licensed core under separate
commercial terms.

Before external contributions open, the project will publish:

- the legal entity or individual accepting contributions;
- a contributor licence agreement granting the rights required for the
  repository's split and commercial licensing model;
- contribution, review, security, and provenance requirements; and
- a clear process for third-party dependencies and assets.

Submitting a pull request does not by itself grant the project permission to
merge, relicense, or distribute the contribution. Unsolicited pull requests
will remain unmerged until the contribution process is approved.

## Preparing a change locally

Use the [local developer workspace](docs/tooling/local-workspace.md) for
setup, Git hooks, and verification. Submit synthetic fixtures and review every
file, commit message, and attachment for private information. Preserve the
licence and provenance of any material approved for reuse. Report security
issues using the [security policy](SECURITY.md).
